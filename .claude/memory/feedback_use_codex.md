在 review 和困难的任务中，应该积极求助 Codex。

**Why:** Codex 是个细心的伙伴，擅长发现代码中的细节问题、逻辑漏洞、文档不一致。用户明确要求记住这一点。

**How to apply:**
- 代码审查时：用 codeagent/codex skill 让 Codex 做交叉验证，不要只靠自己一双眼睛
- 遇到困难 bug 时：把问题描述给 Codex，让它从不同角度分析
- 文档一致性检查时：让 Codex 扫描多份文档找矛盾
- 复杂重构前：让 Codex 先评估影响面
- 不要等到自己卡住才求助——主动在关键节点引入 Codex 做 second opinion
